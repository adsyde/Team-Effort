# Порядок проверки в игре (коротко)

Подробности каждой точки — `docs/TESTING.md`. Игру запускать через `bg3_dx11.exe`, Script Extender
включён (консоль SE открывается сама отдельным окном).

## Шаг 1. Эксперимент DialogKit — 5 запусков на любом сохранении

Нужно сохранение, где Астарион в отряде. Пробные моды — `Загрузки\DialogKit — эксперимент\DialogKitProbe_A…D.pak`,
импортировать все четыре в BG3 Mod Manager. Team Effort, SuccubusPlus и остальное можно оставить:
пробы правят беседу, которую не трогает ни один из них.

Каждый запуск: включить набор в менеджере → экспортировать порядок → запустить игру → загрузить
сохранение → заговорить с Астарионом. После «Ну привет. Чем могу быть полезен?» **последний вариант** —
надпись `[DialogKit …]`. Записать, какая видна (или что её нет), и выйти из игры.

| № | Включить (порядок сверху вниз) | Записать надпись |
|---|---|---|
| 1 | только A | «A банк и подмена пути» / «A только банк» / нет |
| 2 | только B | «B подмена файла игры» / нет |
| 3 | только D | «D совпадение UUID файла» / нет |
| 4 | A, под ним C | «C банк C» / «A …» / нет |
| 5 | C, под ним A | «A …» / «C банк C» / нет |

После — выключить и удалить все четыре пробы.

## Шаг 2. Новая игра, акт 1 — по ходу

Моды: Team Effort, SuccubusPlus, If Fate Chose Differently, MCM (как в профиле сейчас). Если что-то не
так — скриншот и строка из таблицы ниже.

| Когда | Что проверить |
|---|---|
| Первая беседа с проверкой навыка, где у спутника навык выше | В подсказке броска — «Опыт отряда» с разницей в бонусе. До беседы в консоли SE набрать `!te_debug` — журнал сравнения навыков |
| Первый запертый сундук или дверь (взламывает не лучший по «Ловкости рук») | В подсказке броска — «Опыт отряда»; после броска бонуса нет |
| Меню MCM | Есть раздел «Общими силами» |
| **Роща, Тетушка Этель** — главная точка | С Шэдоухарт в отряде: среди ответов героя — «Травница из замшелой глуши…»; выбрать → **говорит Шэдоухарт** (субтитр с её именем), беседа идёт дальше. Если герой — суккуб: там же вариант [СУККУБ] с проверкой харизмы. В MCM выключить «Реплики спутников в беседах героя» → заново заговорить → реплики нет |
| Роща, Нетти (с Астарионом) | «Так это же прекрасно!…» — говорит Астарион |
| Роща, Надира (с Уиллом) и Ашарак, тренер тифлингов (с Лаэзель) | Спутник приходит в беседу и говорит; где стоит, не пропал ли кто-то из отряда, не сломалась ли камера |
| Лагерь гоблинов: Абдирак (Шэдоухарт), Жрица Кишка (Карлах) | Реплика спутника видна и говорит спутник |
| Лагерь, беседа с Уиллом | Вариант «Можно тебя обнять?» (If Fate Chose Differently) есть; при Гейле в отряде — наша реплика про Эльминстера, если тема уже открыта |

## Что прислать

1. Таблицу шага 1: пять надписей.
2. Тетушка Этель: виден ли вариант спутника и кто его сказал (скриншот). **От этого зависит, как
   делать реплики спутников дальше.**
3. Остальные точки — только то, что не сработало, и скриншоты.
4. Текст из консоли SE после `!te_debug` на одной проверке в беседе.
