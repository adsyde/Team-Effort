## Решения автора

- Моды работают согласованно: только дополняют игру и друг друга, ничего не затирают, каждый корректно
  работает один. Общий слой — DialogKit; SuccubusPlus подключается своими патчами; если ему что-то
  нужно — давать промпт.
- Делаем свой мод, а не берём Best in Party Skills; с ним и с Use highest modifier не включать.
- Реплики игрока не озвучиваем: в игре ни один вариант игрока не озвучен.
- Мысли курсивом (`<i>Задуматься…</i>`) спутнику не отдаём.
- Скрытность и карманные кражи не делаем: у каждого они свои.
- PR сливаю сам (squash): правило `Bash(gh pr merge:*)` в `Repo/Games/BG3/.claude/settings.local.json`.
