# Регламент работы Claude Code в репозитории

## 1. Проект
Мод BG3 «Team Effort» («Общими силами»; Patch 8 Hotfix 9, нужен Script Extender): проверки навыков в беседах и в мире —
по лучшему в отряде; уникальные реплики спутников в беседах героя. План — `docs/ROADMAP.md`,
что выяснено — `docs/RESEARCH.md`.

## 2. Порядок работы
- Шаг за шагом: сначала проверяем гипотезу, потом делаем. Одна задача — одна ветка.
- Этап закрыт, когда критерий из ROADMAP проверен в живой игре. Непроверенное готовым не называть.
- Моды других авторов изучать можно, копировать их файлы и тексты нельзя.

## 3. Источники правды
- Механика — только по данным игры: `../AlfiraCompanion/game-data` (диалоги `.lsj`, сценарии Osiris,
  статы, `_story/story_header.div` — сигнатуры функций). По памяти не утверждать.
- Русская терминология — по loca игры (`../AlfiraCompanion/scripts/gamedb.py`): «Отряд»,
  «Проверка навыка», «Испытание».
- В git не добавлять ничего извлечённого из игры.

## 4. Сборка и установка
- `python scripts/build_pak.py` — генерирует статусы, настройки MCM, тексты и реплики спутников, собирает
  `dist/TeamEffort.pak`. Мод зависит от MCM (`meta.lsx`). Все тексты мода — таблица `TEXT` в
  `scripts/gen_stats.py`, ID строк — `data/handles.json` (не менять). В текстах MCM нет `– — … “ ” ‘ ’ №`.
- `python scripts/install.py` — только при закрытых BG3 и BG3 Mod Manager (Redux); порядок пишется
  в `modsettings.lsx` и в файлы менеджера. Вместе с Best in Party Skills и Use highest modifier
  не включать (бонусы сложатся), `--remove-conflicts` их выключает.
- Локализация: `Mods/_MOD_/Localization/<Язык>/TeamEffort_*.xml`, без `<!-- -->` (игра падает).
- UUID мода в `config/tools.json` не менять никогда.
- Игру запускать через `bg3_dx11.exe`.
